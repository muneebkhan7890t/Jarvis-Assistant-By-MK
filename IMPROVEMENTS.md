# MARK LIII: reviewed and improved

This is an edited copy of your uploaded project. The original archive was not changed.

## Added features

**Persistent to-do list:** add tasks with optional details and due dates, list or search them,
mark them complete, reopen them, and archive or restore them.

Try saying or typing:

- "Add finish my voice assistant to my task list."
- "What tasks are still open?"
- "Mark the finish my voice assistant task complete."
- "Show my completed tasks."

**Searchable notes:** explicitly save notes, search their titles and contents, read full
notes, and archive or restore them. These are separate from the existing automatic
personal memory.

- "Save a note called Project ideas: add Urdu commands and a focus timer."
- "Search my notes for Urdu."
- "Read my Project ideas note."
- "Archive my Project ideas note."

The model receives both tool declarations automatically on startup. It can translate
natural-language requests into tool calls; actual voice interpretation still depends
on the existing Gemini session. No new third-party packages are required.

Both features store data in `memory/productivity.db`. Back up this file while the app
is closed. It is local and not encrypted; retrieved results are sent to the model as
part of the conversation. Archive is reversible; ask to restore the item rather than
using the app's existing generic undo command. Lists return 20 results per page.

Task due dates do **not** schedule notifications. Ask to set a reminder separately
when an alert is needed. The existing reminder tool remains available.

## Fixes

- Gemini key resolution is shared by the live session, Gemini-backed actions and
  dashboard. `GEMINI_API_KEY` takes precedence over the saved configuration.
- Missing, malformed or non-object configuration is handled by the shared reader.
  Its error message also works on Windows consoles without emoji support.
- The UI recognises environment-based key setup, and completing setup preserves
  existing unrelated settings.
- Reminders for the same minute get distinct identifiers instead of overwriting
  each other's script or scheduler entry.
- Removed inline comments from ignore patterns for API keys, certificates and
  WhatsApp sessions: Git treats those inline comments as part of the pattern.
- The delivered copy excludes your API-key configuration, personal memory and
  generated bytecode. Set up your key again when using this copy.

## Run on Windows

Extract this folder somewhere writable. Python 3.11 or newer is required by the
existing application's `asyncio.TaskGroup` usage; these tests used Python 3.12.4.
Package and audio compatibility with other Python versions was not verified.

Open PowerShell in the extracted folder:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe main.py
```

Enter your Gemini key in the setup screen. Alternatively, before launching, set it
for the current PowerShell session:

```powershell
$env:GEMINI_API_KEY = "your-key-here"
.\.venv\Scripts\python.exe main.py
```

The existing live-model setting is preserved. API access, model availability,
microphone permissions and audio devices must be verified on your machine.

## Verification

```powershell
python -m unittest discover -s tests -v
```

Tests cover task and note lifecycles, persistence across a module reload, Unicode
search, input validation, task/note isolation, concurrent writes, pagination,
unavailable storage, action discovery and dispatch, key precedence, malformed
configuration, and same-minute reminder identifiers. They also parse every Python
source file. Tests use temporary storage and mocked scheduling; they do not set
real reminders, access your microphone or call a paid API.

The full GUI, live voice, cloud API, OS notifications and remote dashboard were
**not** exercised end to end. This is a focused improvement, not a full security
or cross-platform audit of all existing automation tools.

## Suggested next features

1. **Reminder management:** list, cancel, snooze and repeat existing reminders;
   maintain a local index of scheduler IDs so changes can be verified.
2. **Privacy controls:** explicit toggles for automatic memory and clipboard
   monitoring, plus a visible indicator for audio sent to the cloud.
3. **Offline command mode:** handle a small set of local commands when the live
   connection fails, with clear feedback about unavailable online functions.
4. **Startup diagnostics:** check microphone, speakers, credentials and connectivity
   before starting a session and show specific repair steps.
5. **Urdu/English preference:** expose preferred conversation language in settings
   and test mixed-language commands, names and task titles.
6. **A task-and-notes panel:** show saved items in the GUI with complete/archive/
   restore buttons, building on the database added here.

The project already contains wake-word detection, typed input, memory browsing,
device selection, reminders and screen analysis. Improving reliability and control
of those capabilities is more useful than duplicating them.
